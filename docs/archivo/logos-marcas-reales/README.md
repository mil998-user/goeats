# Logos con marcas reales (sin uso)

Logos de los datos de prueba antiguos que usaban marcas reales: KFC, Burger King, Pollo Campero, TropiBurger y Papa John's. Desde el bloque 8 los locales de prueba usan nombres inventados con logos propios en `frontend/public/logos/`.

Se guardan aquí, fuera de `frontend/public`, para que la web no los publique. No se borraron. Ningún archivo del sistema los usa.
